# 🎵 پخش‌کننده موزیک پیشرفته (Music Player)

یک پخش‌کننده موزیک تک‌فایلی، سبک و کاملاً آفلاین که با **HTML، CSS و جاوااسکریپت خالص** (بدون هیچ فریم‌ورک یا کتابخانه‌ی بیرونی) ساخته شده و از **Web Audio API** برای اعمال جلوه‌های صوتی حرفه‌ای در لحظه‌ی پخش استفاده می‌کند. رابط کاربری آن کاملاً **فارسی و راست‌به‌چپ (RTL)** است و به‌صورت **PWA** (قابل نصب روی موبایل و دسکتاپ) طراحی شده.

---

## ✨ امکانات

### پخش و مدیریت فایل‌ها
- بارگذاری یک یا چند فایل صوتی از روی سیستم (`fileInput`) و ساخت خودکار **فهرست پخش (Playlist)**
- بارگذاری موزیک مستقیم از یک **لینک/URL**
- دکمه‌های پخش/توقف، قطعه‌ی بعدی و قبلی، نمایش نام فایل و موقعیت قطعه در فهرست
- نوار جست‌وجو (Seek Bar) با نمایش زمان سپری‌شده و کل زمان به **اعداد فارسی**
- پشتیبانی کامل از صفحه‌کلید (فلش‌ها، Home، End) برای پیمایش در آهنگ

### جلوه‌های صوتی زنده (Real-time Audio Effects)
همه‌ی جلوه‌ها با گراف صوتی Web Audio API به‌صورت آنی روی صدا اعمال می‌شوند:

| جلوه | توضیح |
|---|---|
| **سرعت پخش** | تغییر سرعت از ۰.۵ تا ۲ برابر |
| **اکولایزر ۳ باند** | تنظیم بیس، میان‌باند و زیر (Treble) |
| **فیلتر بالاگذر / پایین‌گذر** | حذف فرکانس‌های بم یا زیر |
| **دیستورشن (اعوجاج)** | ایجاد صدای خشن و اعوجاج‌یافته |
| **پان (Pan)** | جابه‌جایی صدا بین کانال چپ و راست |
| **ریوِرب (بازتاب صدا)** | با تنظیم اندازه فضا، واخش، تن و میزان اختلاط |
| **دیلی/اکو** | با تنظیم زمان تأخیر، بازخورد و میزان اکو |
| **ترمولو** | نوسان دوره‌ای در بلندی صدا (سرعت و عمق) |
| **حذف صدای خواننده (Vocal Remover)** | کاهش صدای مرکزی میکس برای ساخت نسخه‌ی کاراوکه‌مانند |

### ذخیره‌سازی خروجی
- امکان **ذخیره‌ی فایل نهایی با تمام جلوه‌های اعمال‌شده** روی آن (Export)
- تلاش برای خروجی گرفتن در قالب **MP3** (با بارگذاری پویای انکودر) و در صورت عدم امکان، بازگشت خودکار به فرمت **WAV**
- پردازش آفلاین صدا (Offline Audio Context) برای تولید خروجی با کیفیت بالا، از جمله پیاده‌سازی دستی تغییر سرعت بدون تغییر زیر و بمی (Time-Stretch)

### تجربه‌ی کاربری و دسترسی‌پذیری (Accessibility)
- طراحی راست‌به‌چین با فونت فارسی «وزیرمتن»
- برچسب‌های ARIA کامل، وضعیت زنده (`aria-live`) برای صفحه‌خوان‌ها
- سازگار با حالت تمرکز صفحه‌کلید (`focus-visible`)
- قابل نصب به‌عنوان اپلیکیشن (PWA) با آیکون و مانیفست تعبیه‌شده در همان فایل HTML
- طراحی واکنش‌گرا (Responsive) برای نمایش مناسب روی موبایل

## 🚀 نحوه‌ی اجرا

از آنجا که این پروژه تنها از **یک فایل HTML** تشکیل شده، نیازی به نصب هیچ وابستگی یا اجرای دستور خاصی نیست:

1. مخزن (ریپازیتوری) را کلون یا دانلود کنید.
2. فایل `music_player.html` را در مرورگر خود باز کنید (یا آن را روی یک سرویس‌دهنده‌ی استاتیک مثل GitHub Pages قرار دهید).
3. یک یا چند فایل صوتی از سیستم خود انتخاب کنید یا لینک مستقیم یک فایل صوتی را وارد کنید.
4. با نوب‌های موجود، افکت‌های دلخواه را روی صدا اعمال کنید و در صورت تمایل، خروجی نهایی را ذخیره کنید.

> 💡 برای عملکرد کامل PWA (نصب روی صفحه‌ی اصلی موبایل)، بهتر است فایل را روی یک سرور (مثلاً GitHub Pages) میزبانی کنید، نه اینکه مستقیماً از روی سیستم باز شود.

## 🛠️ فناوری‌های استفاده‌شده

- **HTML5 / CSS3** — رابط کاربری و طراحی واکنش‌گرا
- **JavaScript (Vanilla)** — بدون هیچ فریم‌ورک یا کتابخانه‌ی خارجی
- **Web Audio API** — گراف صوتی، فیلترها، ریوِرب، دیلی و سایر جلوه‌ها
- **Service Worker + Web App Manifest** — قابلیت PWA و اجرای آفلاین
